# LR Expansion Group: showcase site

A mobile-first, dependency-free rebuild of the LR Expansion Group website. Plain HTML, CSS and vanilla JS; no build step.

## Structure
    index.html        page markup
    css/styles.css    design tokens, layout, animation (light and dark theme)
    js/main.js        menu, scroll-built tower, word fill, gallery parallax, WhatsApp form
    images/           hero and site photos (WebP)
    downloads/        brochure and price-guide PDFs
